# v1 evidence assets (tracked)

These files are **real recorded artifacts** from local offline runs.
They are **not** validated LLM adaptation results.

| Asset | Provenance |
| --- | --- |
| `figures/offline_mock_*` | Generated by `rewardbench.analysis report` from scripted-mock ApolloLander SQLite logs |
| `flights/offline_mock_development_episode.flight.json` | Full `.flight.json` from a scripted-mock development episode; `verify_flight_record` matches |
| `figures/offline_v1_matched_*` | 2026-10-24 audit: same development seed panel each revision; explicitly scripted mock |
| `offline_v1_verification.json` | Compact independent audit evidence, code/diff/verifier identity, runtime versions, deterministic outcome and figure hashes |
| `audit-requirements.txt` | Exact audit package snapshot for Python 3.12 on macOS arm64; not a portable lock file |

Labels that apply to every file here:

- Origin: scripted / hand-specified / deterministic mock infrastructure
- `independently_validated`: **false**
- No paid API calls produced these artifacts

Original `offline_mock_*` images and flight are historical evidence from the
earlier rotating development schedule; they are preserved. The new matched-panel
figures are used by README. Neither set establishes LLM adaptation.

Repeat the complete audit (use a new output directory; does not modify this folder):

```bash
python examples/verify_offline_v1.py --out runs/offline-v1-verification
```

Generate a report separately (does not modify this folder automatically):

```bash
python -m rewardbench.run --config configs/apollolander_offline_development_numerical.yaml --mode mock
python -m rewardbench.analysis report --logs runs/apollolander_offline_numerical.sqlite --out reports/offline_numerical
```
